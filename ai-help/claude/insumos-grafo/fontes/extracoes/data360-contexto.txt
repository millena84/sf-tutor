- Data 360 é habilitado em uma org Salesforce existente ou em uma org nova dedicada ("home org"); outras orgs se conectam como "companion orgs" (Data Cloud One).
- Dados ingeridos ficam em Data Lake Objects (DLO), mapeados para Data Model Objects (DMO) do modelo C360; armazenamento em lakehouse.
- Empacotamento e autorização diferem dos da Salesforce Platform; a API mais usada é a Data 360 Connect REST API.
- Acesso ao Data Cloud Setup: perfil System Admin e/ou permission set Data Cloud Architect; licenças próprias (data spaces adicionais exigem add-on).
- Create a Data Space (help sf.c360_a_data_spaces_create.htm): licenças padrão limitadas a um data space; data spaces adicionais exigem licença add-on.
