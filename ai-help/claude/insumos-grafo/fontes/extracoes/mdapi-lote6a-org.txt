[src:mdapi-currencysettings] CurrencySettings: arquivo settings/Currency.settings; desde 47.0; estende Metadata
  Configuração de moedas da org: ligar múltiplas moedas, moedas ativas, moeda corporativa e datas de vigência. Curinga * não vale para um setting
  individual.
  CurrencySettings (7): corporateCurrency | string | 68.0, currency | Currency[] | 68.0, enableCurrencyEffectiveDates | boolean,
    enableCurrencySymbolWithMultiCurrency | boolean, enableMultiCurrency | boolean, isMultiCurrencyActivationAllowed | boolean,
    isParenCurrencyConvDisabled | boolean
    corporateCurrency: código ISO 4217 da moeda corporativa (taxa fixa em 1.0); a moeda precisa estar cadastrada e ativa; sem efeito se
      enableMultiCurrency não for true (antes ou no mesmo deploy).
    currency: entradas de moeda; entrada nova é inserida, entrada com isoCode existente atualiza active, scale e conversionRate; sem efeito sem
      enableMultiCurrency true.
    enableCurrencyEffectiveDates: liga moeda com data de vigência; padrão false; exige enableMultiCurrency true.
    enableCurrencySymbolWithMultiCurrency: mostra o símbolo (true) ou o código ISO (false) em org com múltiplas moedas; padrão false.
    enableMultiCurrency: liga múltiplas moedas; padrão false. A partir da API 68.0, implantar true liga o recurso; em org que já tem, não faz nada.
      A moeda corporativa vem de corporateCurrency (se enviada no mesmo deploy) ou da localidade da org. Ligar é irreversível; implantar false em
      org com múltiplas moedas devolve erro.
    isMultiCurrencyActivationAllowed: descontinuado na API 49.0 e posteriores; não muda se o admin pode ativar múltiplas moedas; visível só com
      múltiplas moedas desligadas; padrão false.
    isParenCurrencyConvDisabled: desliga a conversão de moeda entre parênteses; padrão true; com false, o usuário vê o valor convertido quando a
      moeda pessoal difere da do registro.
  Currency: active | boolean, conversionRate | double, isoCode | string | Required, scale | int
    active: se usuários podem atribuir a moeda a registros; moeda inativa não pode ser a corporativa; padrão true para moeda nova.
    conversionRate: taxa de conversão para a moeda corporativa; 1.0 para a própria corporativa.
    isoCode: código ISO 4217 suportado pela Salesforce; código não suportado devolve erro.
    scale: casas decimais, de 0 a 6.
  Divergência na página: a descrição de conversionRate diz que o campo é obrigatório para moedas novas; a seção do tipo Currency o lista como não
    obrigatório.
