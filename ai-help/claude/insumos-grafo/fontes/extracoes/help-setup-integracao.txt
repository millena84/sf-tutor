Lote 5i (issue #24) — caminhos de Setup das funcionalidades de integração. Leitura em 2026-11-09 de resultados de busca restrita a help.salesforce.com e developer.salesforce.com (texto das páginas oficiais devolvido pela busca).
Rótulos de tela em inglês, como nas páginas; a tradução da interface em pt-BR não foi verificada. Páginas da Ajuda não têm versão.

[src:help-nc-create] Create or Edit a Named Credential — Setup > Quick Find: Named Credentials > aba Named Credentials > New (New Legacy cria a versão antiga). Disponível em todas as edições; criar exige Manage Named Credentials ou Customize Applications.
[src:help-ext-cred-create] Create or Edit an External Credential (fluxos OAuth) — Setup > Quick Find: Named Credentials > External Credentials > New.
[src:help-auth-provider-oidc] Configure an Authentication Provider Using OpenID Connect — Setup > Quick Find: Auth. Providers > New. Edições Enterprise, Performance, Unlimited e Developer; editar exige Customize Application e Manage Auth. Providers.
[src:help-cert-self-signed] Generate a Self-Signed Certificate — Setup > Quick Find: Certificate and Key Management > Create Self-Signed Certificate. Todas as edições; exige Manage Certificates. Máximo de 50 certificados.
[src:help-saml-slo-sp] Configure SAML Single Logout with Salesforce as the Service Provider — Setup > Quick Find: Single Sign-On Settings > (SAML Single Sign-On Settings) New. Editar exige Customize Application e Modify All Data.
[src:help-eca-create] Create an External Client App — Setup > Quick Find: App Manager > New External Client App. Edições Professional, Enterprise, Performance, Unlimited e Developer.
[src:help-eca-jwt] Configure an External Client App to Issue JWT-Based Access Tokens — Setup > Quick Find: External Client Apps > External Client App Manager > (app) > Edit Settings / Edit Policies.
[src:help-eca-custom-scope-assign] Assign an OAuth Custom Scope to an External Client App — Setup > Quick Find: External Client Apps Manager > (app) > Policies > OAuth Policies > selecionar os escopos customizados. O caminho de criação do escopo não foi lido.
[src:help-connected-app-basics] Configure Basic Connected App Settings — Setup > Quick Find: External Client Apps > External Client App Settings > New Connected App; a página remete à restrição de criação de connected apps a partir do Spring '26.
[src:help-remote-site] Configure Remote Site Settings — Setup > Quick Find: Remote Site Settings > New Remote Site. Edições Enterprise, Performance, Unlimited, Developer e Database.com; exige Customize Application ou Modify All Data.
[src:help-cors] Configure Salesforce CORS Allowlist — Setup > Quick Find: CORS > New (Origin URL Pattern). Exige Modify All Data.
[src:help-trusted-urls] Manage Trusted URLs — Setup > Quick Find: Trusted URLs > New Trusted URL. A tela se chama Trusted URLs; cada item tem diretivas CSP. Exige Customize Application e Modify All Data.
[src:help-event-relay-create] Create an Event Relay — Setup > Quick Find: Event Relays > New Event Relay (assistente: rótulo, named credential, canal, opção de recuperação de erro). O relay nasce parado.
[src:help-external-services-register] Paste the JSON or YAML formatted Schema — Setup > Quick Find: External Services > New External Service.
[src:help-external-data-source-odata] Define an External Data Source for Salesforce Connect (OData 2.0 ou 4.0) — Setup > Quick Find: External Data Sources > New External Data Source.
[src:help-platform-events-define] Define and Manage Platform Events — Setup > Quick Find: Platform Events > New Platform Event. Edições Performance, Unlimited, Enterprise e Developer; exige Customize Application. O nome de API recebe o sufixo __e.
[src:pe-guide-subscribers] View and Manage an Event's Subscribers on the Platform Event's Detail Page (Platform Events Developer Guide) — Setup > Quick Find: Platform Events > (evento) > lista Subscriptions > Manage > Suspend, Resume ou Resume from Tip.
[src:pubsub-qs-events] Step 3: Set Up Events (Pub/Sub API quick start) — Setup > busca: Change Data Capture > selecionar os objetos.
[src:help-bulk-jobs] Monitor Bulk Data Load Jobs — Setup > Quick Find: Bulk Data Load Jobs (acompanhar jobs em andamento e concluídos; concluídos saem da lista após 7 dias). Edições Enterprise, Performance, Unlimited, Developer e Database.com.
[src:help-snowflake-private-connect] Define a Named Credential for Salesforce Connect SQL Adapter for Snowflake — Setup > Quick Find: Private > Private Connect > Create Outbound Connection > AWS PrivateLink.
[src:commerce-extensions-guide] Get Started with Salesforce Commerce Extensions (developer.salesforce.com) — o provedor é registrado por API (Commerce Extension Providers) ou inserindo RegisteredExternalService; a página não traz caminho de Setup.
