  campos-chave e orientação aparecem também em kanban views do mesmo objeto, record type e picklist; o path aparece para quem vê o registro,
  o record type e todos os campos do path.

  até cinco campos-chave e até 1.000 caracteres de orientação por etapa.

  aberto até o usuário recolher.

  path para o record type específico.
[src:help-quick-actions-kb] Quick Actions (artigo 000265875): ações de objeto criam ou atualizam registros no contexto de um objeto, com
  relação automática; ações de atualização precisam ser de objeto; quick actions podem chamar Lightning components, flows, páginas Visualforce
  e canvas apps.
[src:help-quick-action-considerations] Quick Action Considerations: record types podem esconder ações; para ver uma ação de objeto no page
  layout, é preciso Read e Edit no campo de relacionamento da ação.

  campos com dados da página); ficam no global publisher layout.

  global publisher layout.

  Actions, as ações vêm do global publisher layout e dos botões do page layout; depois, vale a ordem da seção.
[src:help-actions-page-layout-editor] Customize Actions with the Enhanced Page Layout Editor: a categoria Mobile & Lightning Actions reúne quick
  actions, productivity actions, ações de Lightning component e botões padrão e customizados.
[src:help-flow-quick-action] Run a Screen Flow From a Quick Action: o flow precisa estar ativo; quick actions que rodam flows só como ações de objeto.
[src:help-flow-list-button] Run a Flow from a Custom List View Button: Setup, Object Manager, objeto, Buttons, Links, and Actions, New Button or Link.
[src:help-custom-tabs-overview] Custom Tabs: mostram dados de objeto customizado ou conteúdo web; quatro tipos (custom object, web, Visualforce,
  Lightning page); no Lightning Experience, a tab de um app aparece na barra de navegação e no App Launcher.
[src:help-custom-tab-considerations] Custom Tab Considerations: limite fixo por edição, sem aumento; objeto com custom tab é pesquisável por padrão.
[src:help-vf-tabs] Create Visualforce Tabs: Setup, Quick Find "Tabs", New em Visualforce Tabs.
[src:help-app-builder-limits] Lightning App Builder Limits and Limitations: Default On/Off de Lightning page tabs não funcionam como nas outras

[src:help-page-layouts] Page Layouts: controlam botões, campos, s-controls, Visualforce, links e related lists nas páginas de registro e ajudam
  a definir campos visíveis, somente leitura e obrigatórios.
[src:help-page-layouts-create] Create Page Layouts: permissão Customize Application; nas configurações de gerenciamento do objeto, Page Layouts, New.
[src:help-kb-page-layout-section] artigo 000385416: no Lightning Experience: Setup, Object Manager, objeto, Page Layouts, Edit.
