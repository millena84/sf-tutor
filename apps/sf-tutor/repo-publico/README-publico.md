# Metadata Desbugado

O Metadata API da Salesforce em mapa, para estudar e consultar: funcionalidades, metadata types, objetos API, propriedades e campos, com as fontes oficiais citadas. Um projeto [Desbugando](https://github.com/millena84/desbugando).

- **Endereço:** https://millena84.github.io/metadata-desbugando/ (GitHub Pages, branch `main`, pasta `/docs`).
- **Origem:** o conteúdo de `docs/` é **gerado**: é o build de `apps/sf-tutor` no repositório de trabalho (privado), feito a partir da base de insumos validada. Não edite `docs/` à mão; cada versão entra por PR.
- **Versão:** `docs/data/build-info.json` informa o commit dos insumos e a data do build. `docs/data/manifest.json` informa o contrato de dados e a versão da API Salesforce de referência.
- **Encontrou um erro?** Use o botão "Reportar erro" na ficha do item, ou abra uma [issue](https://github.com/millena84/metadata-desbugando/issues/new/choose).
